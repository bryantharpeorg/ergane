**This is a seam capture, not a session at a terminal.** Everything below is
*rendered text*: `container_project.py` resolved a project from an injected
`ControlPlaneConfig`, an injected two-repo `Registry` read from a fixture
`repos.json`, and a scratch host under `/tmp/seam-capture` pointed at by


`ERGANE_TEMPORAL_DB_FILENAME` is `engine.db` under the state root: not the
supervisor's landed `/var/lib/ergane/temporal.sqlite`, which nothing mounts, nor
`dev.db`, the native unit's. The **state-root** mount covers it; the supervision
home is its sibling. `TEMPORAL_ADDRESS` is the engine's loopback, `host:port` —
the supervisor's children need the port (R12).

`project_files()` returns four `GeneratedFile`s in `<supervision home>/container`:
`compose.yaml` (0644), `.env` (0600) and copies of the two confinement artifacts
(0644). US3 writes them.
