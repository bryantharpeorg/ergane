# Persona registry example.
#
# This is the shipped example registry.  `ergane install` copies it to
# ~/.config/ergane/personas.yaml on a fresh host.  Replace every placeholder
# alias below with aliases your LiteLLM proxy actually serves.
#
# Nodes are routed by persona, never by model tier.  This registry is the only
# place a model name appears — code never hardcodes one.  The `model` and
# `fallback` values are LiteLLM aliases from the operator's proxy config.
#
# Required fields per persona:
#   agent          adapter name; "none" means deterministic, no key
#   model          LiteLLM alias; required when agent != "none", null when "none"
#   fallback       LiteLLM alias used on primary-model failure; optional (null)
#   skills         backing skills; may be empty (reserved, currently unused)
#   write_scope    worktree | docs | read
#   needs_worktree whether the node runs against an isolated git worktree
#   timeout        attempt wall-clock bound in seconds; null only when agent is "none"
#   context_window model context-window tokens; optional (omit for default behavior)
#
